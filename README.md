## Objective

Improve a supplied TensorFlow/Keras CNN by experimenting with
hyperparameters and selecting the best model using validation accuracy.

The notebook uses a selected subset of CIFAR-100 classes.

## Results

| Metric | Accuracy |
|---|---:|
| Baseline validation accuracy | 56.02% |
| Best validation accuracy | 62.88% |
| Final test accuracy | 63.92% |

Best validation accuracy improved by **6.86 percentage points**.
The test set was reserved for evaluation after tuning.
